# HYBRAHEEEM-ACADEMY
HYBRAHEEM ACADEMY is an all-in-one Islamic Studies e-learning platform built for Junior &amp; Senior Secondary School students in Nigeria. We make learning your Deen simple, engaging, and exam-ready. Our content is strictly aligned with the NERDC/UBEC curriculum and covers the five core branches of Islamic Studies: Qur'an, Hadith, Tarikh, Tawhid &amp; Fiqh
